プライバシーポリシー

最終更新日：2026年10月5日

「Topic Gacha」（以下、「本アプリ」）は、 ユーザーのプライバシーを尊重し、情報を適切に取り扱います。

本プライバシーポリシーでは、本アプリにおける情報の収集、 利用および取り扱いについて説明します。

1. 収集する情報

本アプリでは、アプリの利用状況の分析および品質改善のため、 Google LLC が提供する Firebase Analytics および Firebase Crashlytics を使用しています。

アプリの利用状況

本アプリでは、以下のようなアプリ内操作に関する情報を収集する場合があります。

  • カテゴリの選択
  • 通常ガチャおよび10連ガチャの利用
  • 話題のお気に入り登録および解除
  • お気に入りからのガチャ利用
  • ストック機能の利用
  • 図鑑機能の利用
  • レアな話題の取得
  • カテゴリまたは図鑑のコンプリート
  • 会話セッションの開始および終了
  • 会話セッションでの「次の話題」「スキップ」「盛り上がった」などの操作

これらのイベントでは、カテゴリ、レア度、セッション種別、 フィードバック内容、完了した話題数、 話題ID（topic_id）などの情報を利用する場合があります。 カテゴリは、画面の表示言語に依存しない区分として記録します。

本アプリでは、話題の本文そのものを分析データとして送信しません。

一部の利用状況分析では、どの話題に対する操作であるかを把握するため、 アプリ内で定義された話題ID（topic_id）を送信する場合があります。

この話題IDはアプリ内の話題を識別するための固定IDであり、 氏名、メールアドレスなど、ユーザーを直接識別する情報は含まれていません。 ユーザーが入力した文章を、話題IDとして送信することもありません。

また、ユーザーを直接識別するための独自のユーザーIDを Analyticsへ設定していません。

端末およびアプリに関する情報

Firebase Analytics および Firebase Crashlytics により、 以下のような情報が収集される場合があります。

  • アプリのバージョン
  • Android OSのバージョン
  • 端末の種類およびモデル
  • アプリの利用状況
  • アプリのクラッシュおよびエラー情報
  • 診断情報
  • アプリインスタンスに関連する識別子
  • Firebase Installation IDなどのインストール単位の識別子
  • 広告IDなどの端末またはその他の識別子
  • IPアドレスから推定されるおおよその位置情報

本アプリでは、氏名、メールアドレス、電話番号、住所、ログイン情報など、 ユーザーを直接特定するための情報をアプリ独自に収集することはありません。

また、本アプリでは独自のユーザーIDを設定していません。

2. 情報の利用目的

収集した情報は、主に以下の目的で利用します。

  • 本アプリの利用状況の分析
  • 人気のあるカテゴリや機能の把握
  • 会話セッションなど各機能の利用状況の把握
  • アプリの品質改善
  • クラッシュおよび不具合の調査
  • アプリの安定性向上

収集した情報を、広告目的のプロファイリングや 個人を特定する目的で利用することはありません。

3. FirebaseおよびGoogleによる情報の処理

本アプリでは、Google LLC が提供する以下のサービスを利用しています。

  • Firebase Analytics
  • Firebase Crashlytics

これらのサービスを通じて収集された情報は、 Googleのサービスおよびプライバシーポリシーに従って処理されます。

4. 情報の第三者提供

本アプリは、広告ネットワークとの連携や、 収集したデータの販売を行っていません。

本アプリでは、Firebaseサービスを通じてGoogleがデータを処理します。

Google AnalyticsのGoogleシグナル機能および Google広告との連携は、本アプリでは使用していません。

法令に基づく場合を除き、本アプリの開発者が収集した情報を 第三者へ販売することはありません。

5. 通信時の安全性

Firebase AnalyticsおよびFirebase Crashlyticsとの通信は、 適切な暗号化された通信を使用して行われます。

6. 端末内に保存されるデータについて

本アプリでは、機能を提供するため、 以下のような情報を端末内に保存または一時的に保持します。

  • お気に入りに登録した話題の情報
  • 図鑑で取得済みとなった話題の情報
  • ストックに表示する話題の履歴
  • 会話セッションの進行状態

お気に入りや図鑑などの保存データそのものを、 本アプリの開発者が運営するサーバーへ送信することはありません。

会話セッション内の「盛り上がった」の選択状態についても、 ユーザー間で共有したり、 本アプリ独自のサーバーへ保存したりする機能はありません。

ただし、会話セッション機能の利用状況を把握するため、 「盛り上がった」などの操作が行われたこと自体を Firebase Analyticsのイベントとして記録する場合があります。 この際、話題の本文そのものは送信しません。 どの話題に対する操作であるかを把握するため、 アプリ内で定義された話題ID（topic_id）を送信する場合があります。 この話題IDは、ユーザーを直接識別する情報を含みません。

また、端末のバックアップ設定によっては、 AndroidまたはGoogleのバックアップ機能により、 端末内の一部データがユーザーのバックアップ先に保存される場合があります。

7. データの削除

本アプリにはユーザーアカウントおよびログイン機能はありません。

お気に入りとして端末内に保存されているデータは、 アプリ内のお気に入り機能から削除できます。

ストックに保存されている話題は、 アプリ内から個別または一括で削除できます。

Firebase Analytics、Firebase Crashlyticsおよび関連サービスによって 収集された情報について、削除に関するお問い合わせがある場合は、 下記の問い合わせ先までご連絡ください。

内容を確認のうえ、可能な範囲で対応いたします。

8. アプリのアンインストールについて

本アプリをアンインストールすることで、 端末内に保存されている本アプリのデータは通常削除されます。

ただし、Firebase Analytics、Firebase Crashlyticsなどの外部サービスによって 既に収集された情報については、 それぞれのサービスのデータ保持方針に従って保持される場合があります。

また、端末のバックアップ機能に保存されたデータについては、 ユーザー自身のバックアップ設定により保持される場合があります。

9. お子様の利用について

本アプリは、特定の年齢層の子どもを対象としたアプリではありません。

本アプリでは、ユーザーの氏名、住所、連絡先などの個人情報を 直接入力させたり、アプリ独自に収集したりする機能は提供していません。

10. プライバシーポリシーの変更

本アプリは、機能追加、利用サービスの変更、法令その他の事情に応じて、 本プライバシーポリシーを変更する場合があります。

変更後のプライバシーポリシーは、 本ページに掲載した時点から適用されます。
